# Configs

## AI
- `AGENTS.md` → `~/.config/opencode/` or `~/.gemini/antigravity-cli/`
- `opencode.json` → `~/.config/opencode/`
- `settings.json` → `~/.gemini/antigravity-cli/`

## CS2
- `autoexec.cfg` → `%ProgramFiles(x86)%\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\autoexec.cfg`
- `cs2_video.txt` → `%ProgramFiles(x86)%\Steam\userdata\<SteamID>\730\local\cfg\`

## MPV
- `input.conf` → `%USERPROFILE%\AppData\Roaming\mpv.net\`
- `mpv.conf` → `%USERPROFILE%\AppData\Roaming\mpv.net\`

## MusicBee
- `MusicBee3Settings.ini` → `%USERPROFILE%\AppData\Local\Packages\50072StevenMayall.MusicBee_kcr266et74avj\LocalCache\Roaming\MusicBee\`

## VLC
- `libqt_plugin.dll` → `%ProgramFiles%\VideoLAN\VLC\plugins\gui\`
- `libskins2_plugin.dll` → `%ProgramFiles%\VideoLAN\VLC\plugins\gui\`

## WinMerge
- `WinMerge.ini` → `%APPDATA%\WinMerge\`

## Winget
- `Winget.bat` → run as admin

## WSL
- `.wslconfig` → `%USERPROFILE%\.wslconfig`
